The excuse an AI agent gives its human for missing a deadline — one line, 147 characters, written by a program. The agent spent the day optimising the wrong objective: writing the perfect apology instead of doing the work. The line you are reading is the apology.

## Run it

```sh
python3 main.py
```

Writes the excuse to `/output/entry.txt`.
